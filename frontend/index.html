What the model is doing

1. Clean price history

Downloads adjusted closes, forward-fills market holidays, and clips extreme daily return outliers.

2. Cluster related assets

Uses Hierarchical Risk Parity to group assets by correlation before assigning capital.

3. Apply a portfolio floor

Maintains a minimum holding size so the allocation does not collapse into one dominant name.

4. Test it forward

Trains on a rolling window, trades the next period, and compares the result with the benchmark.
